CPU / WebGPU parity

viewer/model.js is pinned against HuggingFace on the Python side (tests/test_model_conformance.py), but that pins the CPU backend. The WebGPU kernels cannot be executed in a headless CI container, so this page is where they get verified: it runs one forward pass through both backends over identical weights and reports the largest disagreement. It has been run on real hardware and passed. Since CI cannot run it, this page is the only thing that catches an arithmetic regression in a kernel — so run it again after changing one.
